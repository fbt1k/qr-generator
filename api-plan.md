# Архитектурный план проекта (API Plan)

Программа разделена на два независимых слоя: логика генерации и интерфейс взаимодействия с пользователем.

## 1. Логика генерации (`generator.py`)
Предоставляет функцию для создания изображения кода:
- `create_qr_code(data: str, filename: str, color: str) -> Path`
  - `data` — строка для кодирования (текст или URL).
  - `filename` — имя сохраняемого файла (по умолчанию `qrcode.png`).
  - `color` — цвет заливки модулей QR-кода (по умолчанию `black`).
  - *Возвращает:* объект `pathlib.Path` к созданному файлу на диске.

## 2. Интерфейс командной строки (`main.py`)
Точка входа в приложение. Отвечает за:
- Парсинг аргументов командной строки при запуске: `python main.py "текст" [флаги]`.
- Обработку ошибок (например, если у пользователя нет прав на запись файла).
- Вывод логов в терминал (успешно/ошибка).

## Технические стандарты:
**План: Использовать формат PNG для сохранения всех QR-кодов.**
