# Заметки по разработке: Генератор QR-кодов (CLI-утилита)

## Идея проекта:
Создать удобный консольный инструмент для генерации кастомных QR-кодов. Утилита должна принимать данные (ссылки, текст) из терминала, настраивать цвета и сохранять готовый результат в файл.

## Стек технологий:
- Язык программирования: Python 3
- Сторонние библиотеки: `qrcode`, `pillow` (для генерации графики)
- Встроенные модули: `argparse` (для парсинга флагов терминала), `pathlib`
